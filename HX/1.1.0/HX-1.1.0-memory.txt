HX 1.1.0 - PEAK MEMORY MEASUREMENTS (10 November 2026)
Michael Hugh Harrington. Peak memory = maximum resident set size of the hx process (Linux wait4 ru_maxrss), one run each.
Machine: Linux cloud machine, 2 cores, 7 GiB. Build: HX 1.1.0 (source sha256 in the release folder), g++ -O2, static.
Data (public): enwik8 (Hutter Prize text), the Snappy test set, asl16.nii / asl32.nii (neuro images).
  e16 / e32 / e64 = first 16 / 32 / 64 MiB of enwik8
  m128 / m256 = first 128 / 256 MiB of enwik8 + Snappy set + asl16 + asl32 + asl32 + enwik8 again
