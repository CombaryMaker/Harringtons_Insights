Bug found and fixed by this test: tshark 4.6 writes "[TCP PDU reassembled in N]" in the Info column; hs_shark 1.1 (written
against tshark 4.2) did not translate that N from shard frame numbers to original ones, so 4,808 of 964,896 lines differed.
1.2 adds "reassembled in " to the Info rewrite list; all lines then match. Cloud 2-core results (1.31-1.75x) stand.
Harness notes: a PowerShell redirect of tshark's stdout re-encodes it as UTF-16 - use cmd redirection and compare with line
endings normalised; hs_shark's own status line goes to stderr, which PowerShell treats as an error under "Stop".
