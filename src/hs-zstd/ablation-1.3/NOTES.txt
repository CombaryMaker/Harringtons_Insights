hs_zstd 1.3-ablation - test build contributed by Andrew Goodwin (University of Sydney), 2026-11-01, MIT like 1.2.
What it adds to hs_zstd 1.2 (verified by diff, nothing else changed, .hsz format identical):
  --sets 0..3   cap on k-means sets; 0 = plain block splitting in file order (fair Sets baseline; also turns raw rule off)
  --raw entropy|test|off   raw-window rule: 1.2 entropy rule / zstd level-1 trial (2 MB window) / none
  --smooth 1.2|safe        safe never relabels a compressible short run as RAW
  --flush                  decode: msync+fsync (FlushViewOfFile+FlushFileBuffers on Windows) before timing stops
  removed unused copy_n() and a self-assignment no-op
Outcome (cloud sizes, see results-cloud-2026-11-01.txt): the 1.2 entropy raw rule hurts; Sets with --raw off beat plain
block splitting by up to 9% on interleaved data and are neutral on Silesia. Multi-core speed run still to do on the desktop.

DESKTOP RUN 2026-11-01 (results-desktop-2026-11-01.txt; Ryzen 5 7500X3D 6c/12t, 15 GB, Windows, zstd 1.5.6, 12 jobs, 5 decode rounds, --flush, SHA-256 verified)
- Sizes identical to the cloud run and to Andrew's. Every file written by 1.3 defaults decoded exactly by the published 1.2 exe.
- Speed: these files (24-212 MB) decode in 0.03-0.2 s, so 12-thread timings are dominated by process start-up and are only
  indicative. Silesia joined 212 MB: zstd 0.201 s, zstd -T12 0.208 s, pzstd 0.101 s, hs_zstd 1.3 16 MB 0.148 s (4 MB 0.126 s).
  pzstd led here, unlike the 2 GB race (hs_zstd 0.69 s vs pzstd 0.94 s); note hs_zstd ran with --flush (fsync before the clock
  stops) and pzstd did not, and the raw-rule change does not touch the decode path. Large-file speed claims stay with the 2 GB table.
- 1.4-test options (Andrew's design suggestions): --merge 0.1 changed nothing on switch_1mb and Silesia and cost 4.4% on
  dup_random_chunks (it merged the two sets that were helping); --autok 0.2 chose the same sets as 1.3 everywhere; --autok 0.3
  chose 2 sets on Silesia for 0.1% less size and no speed change. Neither earns a default; both stay as options.
