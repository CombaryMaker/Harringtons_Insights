PARAGRAPH CONTEXT EXPERIMENT (10 Nov 2026) - Michael Hugh Harrington. Small test model para.cpp (CC0), cloud machine.
Size = the model's code length in bytes, plus any stored labels. Public texts (Project Gutenberg, header/footer removed):
Pride and Prejudice (pg1342), Frankenstein (pg84), Adventures of Sherlock Holmes (pg1661); nonfiction: Calgary book2.

Variants: base = 11 plain guessers. C = control, 2 more plain guessers. A = free paragraph structure (paragraph type
from its first character - dialogue or not - the last two paragraph types, sentence and word number in the paragraph).
B = stored paragraph label (k-means groups from each paragraph's make-up; label cost included). +m = blend chosen by
the paragraph type/label. RO = paragraphs reordered: dialogue paragraphs first, the rest after (1-bit type per
paragraph stored to undo it; cost included in the RO lines).

FINDINGS
  - A (free paragraph structure) beat the equal-size control on all three novels and added on top of it (A + C better
    than C everywhere, book2 included).
  - Reordering paragraphs by type helped the context-mixing model on all three novels, most on Pride and Prejudice
    (dialogue and narration both large), and helped HX Fast and xz there; bzip2 lost on every book.
  - Best combination, reorder + A + C: Pride and Prejudice 0.57% smaller than the control (0.69% smaller than base),
    Frankenstein 0.20%, Sherlock 0.17%.
  - Stored k-means labels (B) and switching the blend by type (+m) made every book larger.
  - Caution: a small model; gains often shrink inside a strong model such as paq8px, which already tracks some
    paragraph facts.
